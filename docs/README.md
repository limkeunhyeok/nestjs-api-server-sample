# 프로젝트 문서화 (Documentation)

이 디렉토리는 프로젝트의 설계 방향, 기술적 합의, 기능 규격 및 API 요구사항 명세를 체계적으로 기록하고 관리하는 공간입니다.

---

## 구조 (Structure)

| 경로 | 용도 | 설명 |
| :--- | :--- | :--- |
| [`adr/`](./adr/) | 아키텍처 의사결정 기록 (MADR 4.0.0) | 기술 선택, 아키텍처 설계 등 번복하기 어렵고 중요한 기술적 합의 기록 |
| [`specs/`](./specs/) | 기능 및 API 요구사항 명세 | 개별 기능 설계, 데이터 모델 및 API 인터페이스 세부 스펙 명세 |

---

## 문서화 규칙 (Conventions)

* **언어 (Language)**:
  - 개인 프로젝트의 성격에 맞추어 모든 문서는 **한국어(한글)** 작성을 원칙으로 합니다. 불필요한 한영 병기나 복잡한 외래어 표기는 최대한 지양합니다.
* **파일명 (File names)**:
  - 모든 문서는 소문자 하이픈 조합의 `kebab-case.md` 형식으로 명명합니다.
  - 아키텍처 의사결정 기록(ADR)의 경우 4자리 순차 번호 접두사를 부여합니다 (예: `0001-ddd-hexagonal-architecture.md`).
* **상태 필드 (Status)**:
  - 각 문서(ADR 및 Spec)는 최상단에 프론트매터(Front-matter)를 달아 현재 문서의 검토 및 구현 상태(`status`)를 명확하게 드러내어야 합니다.
